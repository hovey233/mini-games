# 网页小游戏合集

一个纯前端、单文件、双击即玩的小游戏大厅。无需安装、无依赖、无后端，所有游戏都打包在单个 HTML 文件里。

## 游戏列表

| 游戏 | 文件 | 简介 |
|------|------|------|
| 💣 扫雷 Minesweeper | `扫雷.html` | 三档难度、首点保护、插旗、和弦快开、计时 |
| 🟦 俄罗斯方块 Tetris | `tetris.html` | 7 种方块、消行计分、等级递进、下一块预览 |
| 🟧 打砖块 Breakout | `breakout.html` | 拖动挡板、多关卡、计分闯关、生命值 |
| ⚫ 五子棋 Gobang | `gobang.html` | 15 路棋盘、AI 对战 / 双人模式、攻防判定 |
| ✈️ 飞机大战 Plane | `plane.html` | 躲避弹幕、自动开火、敌机计分、关卡递进 |

## 运行

直接用浏览器打开 **`index.html`** 进入游戏大厅；点击任意卡片即可开始，游戏页左上角都有「🏠 大厅」按钮一键返回。
