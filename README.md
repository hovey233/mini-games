# 扫雷 Minesweeper

一个纯前端、单文件、双击即玩的扫雷小游戏。无需安装、无依赖、无后端。

## 特性
- 三档难度：初级 9×9（10 雷）/ 中级 16×16（40 雷）/ 高级 16×30（99 雷）
- 首点保护：第一次点击的格子周围 3×3 保证无雷
- 左键挖开、右键插旗（旗数实时扣减剩余雷数）
- 和弦快开：在已翻开的数字上再点一下（或左键+右键同时按），旗数对上即自动翻开其余格子
- 计时器、剩余雷数计数、笑脸重开
- 踩雷时显示全部地雷并标出插错的旗；通关自动给剩余雷补旗

## 玩法
打开 `扫雷.html` 即可。数字表示周围 8 格中有几颗雷，把所有非雷格子翻开即获胜。

## 运行
直接用浏览器打开 `扫雷.html`。
